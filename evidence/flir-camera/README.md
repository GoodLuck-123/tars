检查文件：host-fixed-settings.json、host-capture-report.json、host-transfer.json；board-continuity.json包含逐路完整/断线段计数与时间依据；board-summary.json记录正常停止和进程退出；board-final-doctor.json验证部署/库/USB/SDK；release.json锁定实际运行包。图片含室内人物，截图只保留在忽略的.cache目录，不提交Git。
