# 离线三维回放验收 · 2026-10-26

入口 `./livo view [bag/录制目录]`，源码 `viewer/`。在本机浏览器执行真实 WebGL 三维绘制，不需要 ROS master、雷达或外网；服务只监听 127.0.0.1。运行时仅新增锁定的 Pillow 图像转换依赖。

## 浏览器功能

在 Codex 本地浏览器实际检查：

- 今日真机点云正确显示；播放帧数/时间推进，暂停、逐帧、拖至第 151 帧、2× 播放可用。
- 鼠标拖动旋转、滚轮缩放、视角复位；着色和点大小控件可用。
- 切换已有带 JPEG 的包，右侧图片与点云同时更新，并显示记录时间差。
- 390px 窄屏使用上下布局，页面宽度无水平溢出（scrollWidth=innerWidth=390）。
- 构造有 JPEG 文件头但内容损坏的 3 帧包：相机区域显示错误，三维点云与时间轴仍从第 1 帧推进至第 3 帧并正常结束，没有触发全局播放错误。
- 切包期间禁用播放及选包控件，旧帧返回用代际编号丢弃；加载完成后显示新包首帧。
- 非法帧和录制编号返回 HTTP 400，未知路径返回 404；服务仍可读正常帧。

## 边界

按 bag 记录时间做最近邻显示对齐；不验证设备头时间、曝光同步或外参，不将图像投影到点云。点云只显示当前帧，不累计建图。尚未验收真实相机，AVIA 今日包无相机流。支持完整索引 ROS1 bag（可分包）；正在写入的 `.bag.active` 和 ROS2 bag 不在本版范围。服务端选包状态由当前播放器会话共享，单用户使用。
